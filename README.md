# My Skills Collection

这个仓库用于维护和管理 Claude Code 的 skills。

## 目录结构

```
Skills/
├── my-skills/          # 我自己创建的 skills
├── community-skills/   # 从社区下载的 skills
└── README.md          # 本文件
```

## 使用说明

### 自己创建的 Skills
将你自己开发的 skills 放在 `my-skills/` 目录下，每个 skill 建议使用单独的子目录。

### 从其他地方下载的 Skills
从社区或其他来源下载的 skills 放在 `community-skills/` 目录下。

建议在每个 skill 目录中包含：
- skill 的源代码文件
- README 或说明文档
- 相关配置文件

## Skill 开发参考

- **添加新 Skill**: 请参考 [SKILL_GUIDELINES.md](SKILL_GUIDELINES.md) 了解规范要求
- **官方文档**: Claude Code 官方文档
- **示例参考**: 查看 `community-skills/` 目录中现有的 skills
